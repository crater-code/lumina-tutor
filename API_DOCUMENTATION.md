# Book-Bounded Tutoring Chatbot API Documentation

## Overview

The Book-Bounded Tutoring Chatbot API provides endpoints for uploading PDF books, managing book metadata, and interacting with books through a bounded chatbot that only uses content from the uploaded books.

**Base URL**: `http://localhost:8000`

**Version**: 0.1.0
